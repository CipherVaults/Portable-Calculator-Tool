## 3. Coding lessons

- A bare `cargo build` of a wasm32 cdylib embeds absolute source paths of dependencies (the cargo home, so the user name) in panic-location strings, and the bytes then differ between machines. `trim-paths` is unstable on Cargo 1.99.1; `scripts/build-wasm.mjs` remaps the cargo home and the repo through `CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUSTFLAGS` (or `CARGO_ENCODED_RUSTFLAGS` when a path has spaces) and fails if any local path remains.
- Remapped paths still keep the host's separators (`/cargo\registry\…` on Windows), so engine.wasm is reproducible per OS, not across Windows and Linux. CI builds the published one on Linux.
- `tauri::generate_context!` needs `frontendDist` to exist at compile time; `src-tauri` points at `dist/desktop`, so build it (`build-web.mjs --desktop-only`) before compiling the desktop app.
- `#![forbid(unsafe_code)]` works on the Tauri binary crate (the macros generate no `unsafe`).
- Template substitution must be a single pass over the template only; a later global edit (such as removing blank lines) would change inlined CSS/JS after its CSP hash was computed.
- `clippy::assertions_on_constants` fires on `assert!` over consts in tests; use `const { assert!(…) }`.
- Headless Chromium on Windows keeps a minimum window width (about 500 px): `--window-size=375,…` screenshots are a crop of a wider layout and look like overflow. Check phone widths with device emulation (browser pane mobile preset), not the headless window size.
- A "build twice" check that only cleans the final package reuses every dependency artefact; build the second copy in its own empty target dir.
- Never ship from a path another command also writes: a bare `cargo build` overwrote the remapped engine at cargo's output path, and the web build shipped it. The verified build now gets its own path, and every consumer re-scans for local paths.
- A regex that strips `//` comments also strips the rest of a line after `"a//"` or `"http://"`, hiding banned code. Scan raw text and keep banned words out of comments, and prove every rule with a mutant.
- When a lower layer refuses before the op lookup (the WASM input limit), the caller must restore the documented order of checks itself; here the loader asks about the op alone.
- Edge 157 silently ignores `--js-flags=--noexpose_wasm` (also `--no-expose-wasm`, `--no_expose_wasm`, `--expose-wasm=false`, `--jitless`): `typeof WebAssembly` stays "object". A no-WASM test that trusts the flag passes for the wrong reason; assert `typeof WebAssembly` in the page and remove the global with a CDP pre-page script.
- A "zero violations, zero errors" check needs a positive control: inject an inline script into the booted page and require both detectors to see it blocked.
- Browsers request `/favicon.ico` from the site root on their own; on Pages that is a 404 outside the app and a log error. An empty `data:,` icon link stops it (the web CSPs allow data: images).
- A vm context has its own `WebAssembly` intrinsic: leaving it off the sandbox object does not remove it. The mini-DOM deletes it inside the context for its no-WASM windows.
- A focus-trap test that presses Tab fewer times than the modal has stops never crosses the wrap-around edge and passes for the wrong reason; press more times than there are stops, both ways. A mini-DOM that honours `inert` hides a missing trap; it models a browser without `inert`, so the mutant is caught.
- A smoke round trip must compare the stored canonical text with what the last save returned, not with the in-memory object: the engine normalises (the date calendar gains its defaults).
- A save must never be the first thing to touch a document: `DocStore::save` loads an unseen document first, so a corrupt file is backed up and protected instead of overwritten.
- In a non-mobile Edge viewport `innerWidth` includes the scrollbar; layout checks compare against `documentElement.clientWidth`.
- Pruning backups by a time stamp in their name trusts the clock: when it was set back, the backup just written sorts oldest and is pruned at once. Never prune the file just written, and before removing a document read its backup back and compare the bytes.
- A service worker that caches unhashed files (index.html) straight from the network can pair a new sw.js with a stale index from a CDN edge and then delete the only cache that matched it. Put each file's hash in the worker and fail the install on a mismatch, so the old worker stays.
- In IndexedDB a request's error event reaches the transaction's onerror before the abort, while `tx.error` is still null: take the cause from the event's target. A fake that throws synchronously from `put()` never exercises that path.
- With Trusted Types required, writing a script element's text throws; a positive control for script-src then needs a sink Trusted Types does not cover (a dynamic `import()` of a data: URL).
- A layout check for "no clipped text" misses wrapping: check that formatted values have one line box and that no word's range spans two lines, and test the selected (bold, wider) state of tabs.
- Re-rendering a control on its own change event drops focus to <body>; restore it by id with `preventScroll`, and test with real key presses on a closed select.
- Moving a focused element to another parent (replaceChildren) blurs it in Chromium. Refocus it after the move, and only after its new container is unhidden: focus() on an element inside a hidden ancestor does nothing (the mini-DOM models both, so the test caught it).
- An engine field that carries markup (percent-core's `label` with `<br>`) is not something to escape or split in the UI: build each line from the structured fields inside catalog text, render text nodes only, and prove parity by joining the built lines with the engine's separator and comparing with its field. A mutant that shows the label must fail on a visible `<`.
- `Math.round(1e21 * 100) / 100` is 999999999999999868928, below 1e21, so `formatDecimal(1e21)` is a fixed-point string; the exponent form starts above it. Test a formatting change against the old function itself, not a guessed value.
- A subagent that ends its turn while waiting for a background run may never resume: check `git status` and file times before building on a milestone that was reported done, and verify and commit what is there as its own step.
- PowerShell variable names are case-insensitive: a `foreach ($s in …)` loop overwrote `$S` (the scratch path) and sent output into a directory named after the command. Use distinct names in verify scripts.
